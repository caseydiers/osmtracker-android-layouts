# osmtracker-android-layouts
Casey's layouts for the app OSMTracker

This is a refined layout for use in the united states.  It has a few unique features, and the primary one is 'restriction' page, on which you can map both common speed limits, as well as stop signs.  For stop signs I created "Stop With" mapped when it is a two way stop, and you do not have to stop in your direction of travel.  "Stop Against" which is when you do have to stop in your direction.  "All Stop" is for four way stops or other intersections where all traffic must stop.

There are many other pages of tracking, much of which is from the default layouts, but I find that most of those items I end up using voice notes, texts, or photos to map, so I primarily keep the restriction page open.

Don't use OSMTracker while driving, but if you do, this layout is optimized for it.
